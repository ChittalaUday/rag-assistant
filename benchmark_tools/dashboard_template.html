NVFP4 vs FP8 — same model, different weight format

FP8 is 35–40% slower than NVFP4 on this machine (twice the bytes per token) and uses about 6 GB more memory, for roughly the same accuracy. It is still far faster than bf16. Use NVFP4 by default.

What to know

Ollama queues users on some models

lfm2, nemotron-cascade and qwen3.5:9b ignore the 4-way parallel setting: 4 users get the same total throughput as 1 (scaling ×1.0), so the 4th user waits up to 20 s for the first token. vLLM batches requests properly.

Quantisation decides speed

Generation is memory-bandwidth bound on this box. Dense 27B models manage 12 tok/s per user; 3B-active mixture-of-experts models in NVFP4 reach 60–80.

Best small model: granite4:micro (3B)

97% accuracy at 85 tok/s alone and 210 tok/s for 4 users on Ollama — far ahead of other ≤4B models. qwen3.5:2b is also accurate (94%) but Ollama queues users on it; the tiniest models (gemma3:270m, tinyllama, smollm2:360m) are fast but score 42–55%.

Community FP4 quants are hit and miss

Small W4A4/NVFP4 builds from the community were no faster or better than the same-size Ollama models, and two would not load in vLLM (Qwen3-0.6B-FP4, gemma-3-4b W4A4).

Tuning gave nothing

Flash-attention, q8 KV cache and a larger vLLM memory share changed throughput by ≤ 3% (gpt-oss ±9% is within noise) but made vLLM reserve up to 80 GB of the shared 121 GB. Keep the current flags.

vllm-gemma-12b can never start

Its Hugging Face model is gated and the weights were never downloaded, so the container restarts in a loop. Download with a token or remove it. A working substitute is gemma-3-12b w4a16 (tested).

Memory was nearly full

All five original containers together used ~116 of 121 GB. Run Qwen3.6 alone, or Qwen3.6 + gpt-oss with their current limits.

Caveats

One run per setting, 20 requests per level, 31 accuracy questions judged by Qwen3.6 (which also judged its own answers), thinking mode off. The 31 questions are fairly easy, so a small model scoring 97% here is not equal to a 35B model on hard reasoning or long documents. Not tested: Qwen3.5-122B NVFP4, Qwen3.6-27B FP8, Nemotron-3-Nano FP8 (downloads too slow); llama.cpp and the Qwen3.6 MTP-GGUF are still to come.

# Local Company Knowledge Assistant
## Intent
Answer company questions from uploaded documents with citations on the left and a document-derived relationship map on the right. Queries focus/highlight supported connections. Clicking an edge opens its exact supporting passage. Run on the user's M5 Pro (24 GB) with Ollama, entirely local application data and inference. Development uses authenticated Claude and Codex tooling.
## Architecture
One monorepo: Python/FastAPI backend, React/Vite/TypeScript frontend. Parse text/Markdown natively and PDF/DOCX via Docling. SHA-256 hashes deduplicate and detect replacements. SQLite owns documents, chunks, embeddings, validated entity relations and conversation history. Background worker serializes extraction to bound model load. Ollama qwen3.5:9b handles structured extraction and answers; all-minilm:l6-v2 embeds short overlapping chunks. Evaluate LightRAG first; select it only if evidence provenance, updates and local performance meet requirements. Keep evaluation code/report regardless of decision.
## Evidence and retrieval
Nodes and edge labels derive from open model extraction, not predefined words. Require each extracted relation's quote to occur verbatim in its source chunk; reject invalid relationships and surface warnings. Merge normalized entity names conservatively; deletion/replacement removes only that document's evidence and orphaned edges. Combine cosine embedding retrieval with text overlap and graph expansion. Persist conversation context to resolve follow-ups without treating prior answers as documentary evidence. Generate only from selected citations; warn on invalid cited IDs and abstain for missing evidence. Highlight only relevant source-backed edges.
## UI
Calm light workspace with narrow navigation, answer panel, and spacious graph panel. Document upload/progress/error/retry/delete and seeded fictional documents. Chat streaming, history, source panel, graph fit/zoom, node search, keyboard-accessible relation list and responsive panel switching. Loading, empty, model-offline and malformed-response states must be explicit. No fabricated graph in empty state.
## Quality and limits
Python 3.12+, Node 22+. Bound uploads (20 MB), background jobs, chunk/model context, and model timeouts. Loopback-only serving by default; unauthenticated local single-user tool, not production deployment. Strict linters/type checks, backend behavior tests, frontend component tests and browser integration checks. Six fictional company documents with 30 expected questions, including cross-document, follow-up, conflict, and unknown questions. Record latency/quality observations and model issues. No silent model downloads or invented benchmark outcomes.
